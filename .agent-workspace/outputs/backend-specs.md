# Chapter Smith Backend API Specifications

## Overview

This document provides comprehensive specifications for the Chapter Smith backend API, designed to support YouTube chapters functionality with production-ready features including error handling, rate limiting, validation, and comprehensive monitoring.

## Architecture

### Technology Stack
- **Framework**: Next.js 15 with App Router
- **Runtime**: Node.js 20+
- **TypeScript**: Full type safety with comprehensive interfaces
- **External APIs**: 
  - YouTube Data API v3 (video metadata)
  - Anthropic Claude API (chapter generation)
- **Rate Limiting**: Memory-based (Redis recommended for production)
- **Monitoring**: Structured logging with metrics collection

### Design Principles
- **Type Safety**: Comprehensive TypeScript interfaces for all data structures
- **Error Handling**: Standardized error responses with specific error codes
- **Validation**: Input validation at all API boundaries
- **Performance**: Optimized for concurrent requests with proper caching
- **Scalability**: Designed for horizontal scaling with stateless operations

## API Endpoints

### 1. YouTube Transcript API

**Endpoint**: `POST /api/youtube/transcript`

**Purpose**: Fetches video transcripts from YouTube with language fallbacks and auto-generation support.

#### Request Format
```typescript
interface TranscriptRequest {
  url?: string;           // YouTube video URL
  videoId?: string;       // YouTube video ID (alternative to URL)
  options?: {
    languages?: string[];          // Language preference order ['en', 'es', 'fr']
    includeAutoGenerated?: boolean; // Include auto-generated transcripts (default: true)
    fallbackToAnyLanguage?: boolean // Fallback if preferred unavailable (default: true)
  };
}
```

#### Response Format
```typescript
interface YouTubeTranscriptResponse {
  videoId: string;
  title: string;
  duration: number;        // in seconds
  segments: Array<{
    text: string;
    start: number;         // start time in seconds
    duration: number;      // segment duration in seconds
  }>;
  language: string;        // detected language code
  isAutoGenerated: boolean;
}
```

#### Error Codes
- `INVALID_URL`: Invalid YouTube URL format
- `INVALID_VIDEO_ID`: Invalid video ID format
- `VIDEO_NOT_FOUND`: Video not found or private
- `NO_TRANSCRIPT_AVAILABLE`: No captions available
- `TRANSCRIPT_DISABLED`: Captions disabled by creator
- `YOUTUBE_QUOTA_EXCEEDED`: API quota exceeded
- `RATE_LIMIT_EXCEEDED`: Too many requests

#### Rate Limiting
- **Limit**: 100 requests per hour per IP
- **Quota**: YouTube API quota management
- **Headers**: `X-RateLimit-Remaining`, `X-RateLimit-Reset`

### 2. Chapter Generation API

**Endpoint**: `POST /api/chapters/generate`

**Purpose**: Generates timestamped chapters from video transcripts using AI analysis.

#### Request Format
```typescript
interface ChapterGenerationRequest {
  videoId?: string;        // YouTube video ID
  url?: string;           // YouTube video URL
  transcript?: Array<{    // Pre-fetched transcript (optional)
    text: string;
    start: number;
    duration: number;
  }>;
  options?: {
    minChapterLength?: number;     // Minimum seconds per chapter (default: 60)
    maxChapters?: number;          // Maximum chapters to generate (default: 20)
    includeDescriptions?: boolean; // Include chapter descriptions (default: true)
    language?: string;             // Content language (default: 'en')
  };
}
```

#### Response Format
```typescript
interface ChapterGenerationResponse {
  videoInfo: {
    id: string;
    title: string;
    duration: string;
    channelTitle: string;
    publishedAt: string;
    thumbnailUrl: string;
    url: string;
  };
  chapters: Array<{
    id: string;
    timestamp: string;       // "HH:MM:SS" or "MM:SS"
    title: string;
    description?: string;
    startTime: number;       // seconds
    endTime?: number;        // seconds
    confidence?: number;     // 0-1 confidence score
    keywords?: string[];     // extracted keywords
  }>;
  metadata: {
    totalChapters: number;
    averageChapterLength: number;
    processingTimeMs: number;
    model: string;           // AI model used
    language: string;
  };
}
```

#### AI Model Configuration
- **Model**: Claude 3 Haiku (fast, cost-effective)
- **Temperature**: 0.3 (balanced creativity/consistency)
- **Max Tokens**: 4000
- **System Prompt**: Optimized for chapter generation
- **Fallback**: Retry logic with exponential backoff

#### Error Codes
- `MISSING_REQUIRED_FIELD`: Required field missing
- `INSUFFICIENT_CONTENT`: Video too short or empty transcript
- `CHAPTER_GENERATION_FAILED`: AI processing failed
- `AI_SERVICE_UNAVAILABLE`: Anthropic API unavailable
- `PROCESSING_TIMEOUT`: Generation exceeded time limit

### 3. Chapter Export API

**Endpoint**: `POST /api/chapters/export`

**Purpose**: Formats and exports chapters in multiple formats with customization options.

#### Request Format
```typescript
interface ExportRequest {
  chapters: Array<{
    id: string;
    timestamp: string;
    title: string;
    description?: string;
    startTime: number;
    endTime?: number;
    confidence?: number;
    keywords?: string[];
  }>;
  format: 'youtube' | 'text' | 'json' | 'csv' | 'srt' | 'vtt' | 'xml' | 'markdown';
  videoInfo?: {
    title: string;
    channelTitle?: string;
    duration?: string;
    url?: string;
  };
  options?: {
    includeTimestamps?: boolean;   // Include timestamp column (default: true)
    includeDescriptions?: boolean; // Include descriptions (default: true)
    includeVideoInfo?: boolean;    // Include video metadata (default: false)
    customTemplate?: string;       // Custom format template
    timezone?: string;             // Timezone for timestamps (default: 'UTC')
  };
}
```

#### Response Format
```typescript
interface ExportResponse {
  content: string;         // Formatted content
  filename: string;        // Suggested filename
  mimeType: string;        // MIME type for download
  size: number;           // Content size in bytes
  downloadUrl?: string;    // Optional download URL (for large files)
  expiresAt?: string;     // Download URL expiration
}
```

#### Export Formats

| Format | Extension | MIME Type | Description |
|--------|-----------|-----------|-------------|
| `youtube` | `.txt` | `text/plain` | YouTube description format |
| `text` | `.txt` | `text/plain` | Plain text with timestamps |
| `json` | `.json` | `application/json` | Structured JSON data |
| `csv` | `.csv` | `text/csv` | Spreadsheet compatible |
| `srt` | `.srt` | `text/srt` | SubRip subtitles |
| `vtt` | `.vtt` | `text/vtt` | WebVTT format |
| `xml` | `.xml` | `application/xml` | XML structure |
| `markdown` | `.md` | `text/markdown` | Markdown documentation |

#### Format Examples

**YouTube Format**:
```
=ù Video Title
=d Channel Name

ð CHAPTERS:
00:00 Introduction
03:42 Setup Process
08:15 Main Content
```

**JSON Format**:
```json
{
  "chapters": [

      "id": "ch_1234567890_001",

      "startTime": 0,
      "endTime": 222,
      "description": "Getting started...",
      "confidence": 0.95,

  ],
  "metadata": {
    "totalChapters": 8,
    "exportedAt": "2024-01-15T10:30:00.000Z",

```

Returns available export formats and their specifications.

## Error Handling

### Standardized Error Response
```typescript
interface APIErrorResponse {
  success: false;
  error: {
    code: string;           // Machine-readable error code
    message: string;        // Human-readable message
    details?: any;          // Additional context
    stack?: string;         // Development only
  };
  timestamp: string;        // ISO 8601 timestamp
  version: string;          // API version
}
```

### Error Code Categories

#### Validation Errors (400)
- `INVALID_URL`: Malformed YouTube URL
- `INVALID_VIDEO_ID`: Invalid video ID format
- `INVALID_FORMAT`: Unsupported export format
- `MISSING_REQUIRED_FIELD`: Required parameter missing
- `INVALID_FIELD_TYPE`: Incorrect data type

#### Resource Errors (404)
- `VIDEO_NOT_FOUND`: Video doesn't exist or is private
- `NO_TRANSCRIPT_AVAILABLE`: No captions found
- `DOWNLOAD_EXPIRED`: Export download link expired

#### Rate Limiting (429)
- `RATE_LIMIT_EXCEEDED`: Client rate limit exceeded
- `YOUTUBE_QUOTA_EXCEEDED`: Daily YouTube quota exceeded
- `TOO_MANY_REQUESTS`: Server overloaded

#### Processing Errors (500)
- `CHAPTER_GENERATION_FAILED`: AI processing failed
- `AI_SERVICE_UNAVAILABLE`: External AI service down
- `PROCESSING_TIMEOUT`: Request exceeded time limit
- `EXPORT_FAILED`: Export generation failed

#### System Errors (503)
- `SERVICE_UNAVAILABLE`: Temporary service outage
- `DATABASE_ERROR`: Database connection failed
- `EXTERNAL_SERVICE_ERROR`: Third-party service error

## Integration Instructions

### Frontend Integration
```typescript
// Example usage with the existing frontend
import { api } from '../utils';

// Replace the mock API with real endpoints
export const api = {
  validateURL: async (url: string) => {
    const response = await fetch('/api/youtube/transcript', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ url })
    });
    return response.json();
  },

  generateChapters: async (url: string) => {
    const response = await fetch('/api/chapters/generate', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ url })
    });
    return response.json();
  },

  exportChapters: async (chapters: Chapter[], format: string) => {
    const response = await fetch('/api/chapters/export', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ chapters, format })
    });
    return response.json();
  }
};
```

### Error Handling Pattern
```typescript
async function handleAPICall<T>(apiCall: () => Promise<APIResponse<T>>): Promise<T> {
  try {
    const response = await apiCall();
    
    if (!response.success) {
      throw new APIError(response.error.code, response.error.message, response.error.details);
    }
    
    return response.data;
  } catch (error) {
    // Log error and show user-friendly message
    console.error('API call failed:', error);
    throw error;
  }
}
```
